## How I Build

My workflow is AI-first and human-directed. I use AI to move faster from problem definition to working software, while keeping architecture, security decisions, testing, and release approval under deliberate human control.

For consequential actions, I prefer explicit permissions, deterministic policy checks, audit trails, and approval gates over prompt-only safeguards.
